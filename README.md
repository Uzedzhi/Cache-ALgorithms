# симулятор многоуровневого кеша

Небольшой исследовательский инструмент для сравнения алгоритмов вытеснения
кеша на произвольной многоуровневой иерархии, с эталонным сравнением против
идеального кеша.

### Формат конфиг-файла

```
N
size_1 ALGO_1
size_2 ALGO_2
...
size_N ALGO_N
```

`ALGO` - одно из `LRU`, `LFU`, `ARC`, `2Q`, `LIRS` - алгоритмов вытеснения.

### Формат входных данных (stdin)

```
M
d_1 d_2 ... d_M
```

`M` - количество обращений к кешу
`d_i` - i-ое обращение к d_i элементу
